# Image Text Translator

Cloud-based web application for extracting text from images and translating it into multiple languages using AWS services.

## Features

- Upload image files
- OCR text detection
- Text translation
- Multi-language support
- Web-based interface

## Tech Stack

Python, Flask, AWS S3, Rekognition, Translate, JavaScript, Vite

## Project Structure

backend/
frontend/

## Installation

pip install -r requirements.txt

cd frontend
npm install

## Run

python backend/app.py

cd frontend
npm install()   # Run only once
npm run dev

## Future Improvements

- Batch image processing
